# Testdrive
Testdrive is a series of inexpensive, easy to build, no- or low- solder ergonomic split keyboard designs. These designs are all build on existing open spec keyboard layouts and are intended to allow the user to try several different boards in search of the most comfortable.

All Testdrive board use the same assembly tecniques. The core concept is low cost with easy reuse of the more expensive components such as keyswitches and MCU board.

The first series will be various 3x5_n boards such as the Corne mini, Totem, Ferris, and Fifi.
